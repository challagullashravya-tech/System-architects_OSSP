OS Practical 2 – File Copy Using System Calls

## Aim

To develop a C program using the system calls `open()`, `read()`, `write()`, and `close()` to copy the contents of one file into another file.

## Description

In this practical, I developed a C program to copy the contents of `sample.txt` into `copy.txt` using Linux system calls. The program first opens the source and destination files using `open()`. The `read()` system call reads the contents of the source file into a buffer. Then, `write()` writes the data from the buffer into the destination file. Finally, `close()` closes both files. The program displays a message after the file is copied successfully.

## Objectives

- To understand file handling using Linux system calls.
- To use `open()` to open files.
- To use `read()` to read file contents.
- To use `write()` to write data into another file.
- To use `close()` to close files.
- To understand the transition between user space and kernel space.
- To use `strace` to trace system calls.

## System Calls Used

### 1. open()

The `open()` system call is used to open the source file `sample.txt` and the destination file `copy.txt`.

```c
fd1 = open("sample.txt", O_RDONLY);
fd2 = open("copy.txt", O_WRONLY | O_CREAT, 0644);
````

Here, `sample.txt` is opened in read-only mode and `copy.txt` is opened in write mode. If `copy.txt` does not exist, it is created.

### 2. read()

The `read()` system call reads the contents of `sample.txt` and stores them in the buffer.

```c
n = read(fd1, buf, sizeof(buf));
```

The number of bytes read is stored in the variable `n`.

### 3. write()

The `write()` system call writes the data stored in the buffer into `copy.txt`.

```c
write(fd2, buf, n);
```

### 4. close()

The `close()` system call is used to close both files after the copying operation is completed.

```c
close(fd1);
close(fd2);
```

## Program Flow

1. The program starts execution.
2. `sample.txt` is opened using `open()`.
3. `copy.txt` is opened or created using `open()`.
4. The contents of `sample.txt` are read into a buffer using `read()`.
5. The data from the buffer is written into `copy.txt` using `write()`.
6. Both files are closed using `close()`.
7. The message `file copied successfully` is displayed.

## User Space and Kernel Space

The C program runs in user space, but file operations such as opening, reading, writing, and closing files are handled by the Linux kernel.

When the program calls a system call, the request moves from user space to kernel space. The kernel performs the required file operation and then returns the result back to the user-space program.

The basic flow is:

```text
User Space
    ↓
System Call
    ↓
Kernel Space
    ↓
File Operation
    ↓
User Space
```

In this practical, `open()`, `read()`, `write()`, and `close()` are used to request file-handling services from the Linux kernel.

## strace Utility

The `strace` utility is used to observe the system calls generated by a Linux command.

In this practical, the following command was used:

```bash

```

The `cat sample.txt` command reads the contents of the file and displays them on the terminal. Using `strace`, the system calls generated during this process can be observed.

## System Call Sequence

The basic sequence of operations is:

```text
open()
   ↓
read()
   ↓
write()
```
